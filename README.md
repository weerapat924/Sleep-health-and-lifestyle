# คำอธิบายข้อมูล (Data Description)

โฟลเดอร์นี้อธิบายข้อมูลที่ใช้ในโครงงาน **Sleep Health and Lifestyle Analysis**

## 1. แหล่งที่มาและสิทธิ์การใช้ข้อมูล

| หัวข้อ | รายละเอียด |
| --- | --- |
| ชื่อชุดข้อมูล | Sleep Health and Lifestyle Dataset |
| แหล่งที่มาเดิม | (ใส่ลิงก์แหล่งที่มาของชุดข้อมูล เช่น หน้า Kaggle ที่ดาวน์โหลดมา) |
| ประเภทข้อมูล | ข้อมูลตารางเกี่ยวกับการนอนหลับและไลฟ์สไตล์ 1 แถวต่อบุคคล 1 คน |

## 2. ไฟล์ในโฟลเดอร์นี้

| ตำแหน่งไฟล์ | คำอธิบาย |
| --- | --- |
| `data/raw/Sleep_health_and_lifestyle_dataset.xlsx` | ไฟล์ดิบตามที่ได้รับมา **ห้ามแก้ไขด้วยมือ** มี 374 แถว 13 คอลัมน์ |
| `data/processed/sleep_clean.csv` | ข้อมูลที่ล้างแล้ว 374 แถว 15 คอลัมน์ **สร้างจาก** `code/01_clean_data.py` |
| `outputs/` | ตารางสรุปและกราฟ **สร้างจาก** `code/02_analysis.py` |

วิธีสร้างไฟล์ที่ประมวลผลแล้วขึ้นใหม่: วางไฟล์ดิบที่ `data/raw/Sleep_health_and_lifestyle_dataset.xlsx` แล้วรัน `python code/01_clean_data.py` จากนั้นรัน `python code/02_analysis.py` เพื่อสร้างผลวิเคราะห์

## 3. พจนานุกรมข้อมูล (Data Dictionary) ของ `sleep_clean.csv`

ข้อมูลหลังจากทำความสะอาดแล้วมีทั้งหมด 374 แถว 15 คอลัมน์ ตารางต่อไปนี้แสดงชื่อคอลัมน์ ชนิดข้อมูล คำอธิบาย และจำนวนค่าว่างของแต่ละคอลัมน์

| คอลัมน์ | ชื่อคอลัมน์เดิม | ชนิดข้อมูล | คำอธิบาย / ค่าที่เป็นไปได้ | ค่าว่าง |
| --- | --- | --- | --- | ---: |
| `person_id` | Person ID | ตัวเลข | รหัสประจำแถว ตั้งแต่ 1 ถึง 374 | 0 |
| `gender` | Gender | ข้อความ | เพศ ได้แก่ Male (189) และ Female (185) | 0 |
| `age` | Age | ตัวเลข | อายุ หน่วยเป็นปี มีค่าตั้งแต่ 27 ถึง 59 | 0 |
| `occupation` | Occupation | ข้อความ | อาชีพ มี 11 กลุ่ม ได้แก่ Nurse, Doctor, Engineer, Lawyer, Teacher, Accountant, Salesperson, Software Engineer, Scientist, Sales Representative และ Manager (บางกลุ่มมีตัวอย่างน้อยมาก เช่น Manager 1 คน) | 0 |
| `sleep_hours` | Sleep Duration | ตัวเลข | ระยะเวลานอนต่อวัน หน่วยเป็นชั่วโมง มีค่าตั้งแต่ 5.8 ถึง 8.5 | 0 |
| `sleep_quality` | Quality of Sleep | ตัวเลข | คะแนนคุณภาพการนอน (ประเมินเอง) มีค่าตั้งแต่ 4 ถึง 9 | 0 |
| `activity_minutes` | Physical Activity Level | ตัวเลข | ระดับกิจกรรมทางกาย ในชุดข้อมูลมีค่าตั้งแต่ 30 ถึง 90 (หน่วยเป็นนาทีต่อวันตามที่ชุดข้อมูลเดิมระบุ) | 0 |
| `stress_level` | Stress Level | ตัวเลข | คะแนนระดับความเครียด (ประเมินเอง) มีค่าตั้งแต่ 3 ถึง 8 | 0 |
| `bmi_category` | BMI Category | ข้อความ | หมวดดัชนีมวลกาย ได้แก่ Normal (216), Overweight (148) และ Obese (10) โดยรวมค่า Normal Weight เข้ากับ Normal แล้ว | 0 |
| `blood_pressure` | Blood Pressure | ข้อความ | ความดันโลหิตในรูปแบบ "ตัวบน/ตัวล่าง" เช่น 126/83 | 0 |
| `systolic_bp` | (สร้างใหม่) | ตัวเลข | ความดันตัวบน แยกจาก `blood_pressure` หน่วย mmHg มีค่าตั้งแต่ 115 ถึง 142 | 0 |
| `diastolic_bp` | (สร้างใหม่) | ตัวเลข | ความดันตัวล่าง แยกจาก `blood_pressure` หน่วย mmHg มีค่าตั้งแต่ 75 ถึง 95 | 0 |
| `heart_rate` | Heart Rate | ตัวเลข | อัตราการเต้นของหัวใจขณะพัก หน่วยเป็นครั้งต่อนาที มีค่าตั้งแต่ 65 ถึง 86 | 0 |
| `daily_steps` | Daily Steps | ตัวเลข | จำนวนก้าวเดินต่อวัน มีค่าตั้งแต่ 3,000 ถึง 10,000 | 0 |
| `sleep_disorder` | Sleep Disorder | ข้อความ | ภาวะผิดปกติของการนอน ได้แก่ No Disorder (219), Sleep Apnea (78) และ Insomnia (77) | 0 |

**หมายเหตุ**
- จำนวนค่าว่าง (Missing Values) นับจากข้อมูลหลังทำความสะอาดแล้ว จำนวน 374 แถว
- ในไฟล์ดิบ คอลัมน์ Sleep Disorder มีค่าว่าง 219 แถว ซึ่งหมายถึง "ไม่มีความผิดปกติ" จึงถูกเติมเป็น `No Disorder` ในขั้นตอนทำความสะอาด
- มี 242 แถวที่ข้อมูลซ้ำกันทุกคอลัมน์ยกเว้น `person_id` ไม่ได้ลบออกเพราะอาจเป็นคนละคน ควรตรวจสอบกับแหล่งที่มาก่อนสรุปผล
- ชุดข้อมูลนี้มีความสัมพันธ์ระหว่างตัวแปรสูงผิดปกติ (เช่น คุณภาพการนอนกับระดับความเครียด) จึงควรระวังการตีความเชิงสาเหตุ
